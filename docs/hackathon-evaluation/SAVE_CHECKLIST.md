## ⚠️ Huawei Cloud Entegrasyonu İçin Gerekli

### 1. Environment Variables
Aşağıdaki değişkenleri `.env` dosyasına eklemeniz gerekiyor:

```env
# Huawei Cloud CCE Configuration
MOCK_CCE=false
CCE_ENDPOINT=https://cce.cn-north-1.myhuaweicloud.com
CCE_PROJECT_ID=your-project-id
CCE_CLUSTER_ID=your-cluster-id
CCE_TOKEN=your-token

# VEYA AK/SK Authentication
HUAWEI_ACCESS_KEY=your-access-key
HUAWEI_SECRET_KEY=your-secret-key
HUAWEI_REGION=cn-north-1
```

### 2. Test Adımları
1. `.env` dosyasını oluştur
2. Huawei Cloud credentials'ları ekle
3. Backend'i başlat: `npm run dev`
4. Test bağlantısı yap
5. Gerçek pod verilerini çek
