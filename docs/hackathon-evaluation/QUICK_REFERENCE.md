# 📚 Hızlı Referans Kılavuzu

## 🚀 Hızlı Başlangıç

### 1. Projeyi Çalıştırma
```bash
# Backend
npm run dev

# Frontend
cd frontend && npm run dev
```

### 2. Demo Verisi Oluşturma
```bash
npm run generate-demo-data
```

### 3. Test Çalıştırma
```bash
npm test
npm run test:coverage
```
