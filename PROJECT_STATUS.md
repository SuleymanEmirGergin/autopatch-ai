## ☁️ Huawei Cloud Entegrasyonu

### Mevcut Entegrasyon:
- ✅ **Huawei Cloud CCE Scanner**: `RealCCEScanner`
- ✅ **Authentication**: Token-based ve AK/SK
- ✅ **Multi-Region Support**: Yapılandırılabilir
- ✅ **Error Handling**: Comprehensive

### Yapılandırma:
```env
# Huawei Cloud CCE Configuration
MOCK_CCE=false
CCE_ENDPOINT=https://cce.cn-north-1.myhuaweicloud.com
CCE_PROJECT_ID=your-project-id
CCE_CLUSTER_ID=your-cluster-id
CCE_TOKEN=your-token

# Huawei Cloud AK/SK Authentication
HUAWEI_ACCESS_KEY=your-access-key
HUAWEI_SECRET_KEY=your-secret-key
HUAWEI_REGION=cn-north-1
```

### Entegrasyon Dosyaları:
- `src/scanner/RealCCEScanner.ts` - CCE Scanner implementation
- `src/services/huaweiCloudAuthService.ts` - Authentication service
- `src/config/index.ts` - Configuration
